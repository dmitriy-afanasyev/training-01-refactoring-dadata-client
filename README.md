## 🎯 О проекте

Тренировочный проект для изучения и демонстрации различных архитектурных подходов в PHP-разработке.

За основу взято тестовое задание на рефакторинг клиента для DaData API. Исходный код нарушал SOLID, не имел тестов и содержал множество проблем.

**Цели проекта:**
- 📚 **Обучение** — наглядные примеры архитектурных паттернов для других разработчиков
- 🗂️ **Справочник** — готовые решения с документацией для каждого подхода
- 🎥 **Контент** — база для записи обзорных видео на YouTube
- 💼 **Портфолио** — демонстрация навыков для потенциальных работодателей


## 📂 Структура проекта

```
├── before/           # Исходный код ("грязный" клиент для рефакторинга)
├── after/            # Решения с различными архитектурными подходами
│   └── 01-ddd/       # Domain-Driven Design (текущее решение)
│   └── 02-<...> # альтернативное решение с иным архитектурных модходом (в разработке)
├── TASK.md           # Постановка задачи
├── SOLUTION.md       # Описание базового решения
└── README.md         # Этот файл
```

## 🤝 Использование

Клонируйте весь репозиторий целиком:

```bash

code training-01-refactoring-dadata-client
```

Каждое решение в папке `after/` — это самодостаточный Laravel-проект. Перейдите в папку нужного решения и следуйте инструкциям из его README.
